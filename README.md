# Le site vitrine — Mon Repère Canada

Un seul fichier (`index.html`) plus un dossier d'images (`screens/`). Pas de build, pas d'installation : on peut l'ouvrir directement dans un navigateur, ou le mettre en ligne tel quel.

## Mettre ce site en ligne gratuitement avec GitHub Pages

1. Crée un nouveau dépôt sur GitHub (par exemple `mon-repere-canada-site`).
2. Mets `index.html` et le dossier `screens/` à la racine de ce dépôt.
3. Dans le dépôt GitHub : **Settings → Pages → Source : "main" (ou "master"), dossier "/ (root)"**. Sauvegarde.
4. Après une ou deux minutes, le site est en ligne à une adresse comme `https://<ton-nom-utilisateur>.github.io/mon-repere-canada-site/`.
5. Si tu veux que ce soit `monreperecanada.ca` directement (le même nom que l'appli) : dans les réglages GitHub Pages, ajoute un "Custom domain", puis chez Namecheap, ajoute les enregistrements DNS que GitHub te montre. Dis-moi si tu veux de l'aide pour cette étape précise.
